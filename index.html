Features

Everything You Need

A complete full-stack physiotherapy platform built with Node.js and MongoDB

14+ Exercise Library

Neck, shoulder, back, knee, ankle, leg and hand exercises — each with real images and detailed step-by-step instructions.

Custom Routine Builder

Pick any exercises, set repetitions and cycles, save to MongoDB. Build as many routines as you want.

Guided Workout Timer

30-second countdown per set, automatic 15-second rest periods, pause/resume, skip controls and cycle tracking.

Progress Tracking

6-week calendar heatmap, day streak counter, total workouts, exercises done and minutes active.

MongoDB Backend

Real full-stack app — user accounts, routines and progress all stored securely in a MongoDB database.

Admin Dashboard

Add, edit, delete exercises. View all registered users and monitor every workout log in one place.
